Neither component takes a `stickyGate` prop anymore; there's only one value to use.

**Content conventions**
- Narrative body copy (case-study paragraphs and list descriptions, including Challenge/Solution prose) uses regular body weight by default — keywords, tool names, numbers, and impact/contribution claims should not be automatically bolded for emphasis. Structural labels (e.g. `CalloutNote`'s "Note:"/"NDA Note:" prefix) and all headings/subheadings are unaffected by this rule and keep their established weights.
- **No emoji anywhere in portfolio UI or copy** — headings, paragraphs, lists, labels, captions, navigation, cards, callouts, or accessible text, on any route or in any shared/conditionally-rendered component. This is a hard rule going forward, not just a one-time cleanup (see the changelog entry above for the last full audit and removals) — don't reintroduce an emoji as a section-heading decoration, a component's default icon prop, or anywhere else, even as a "small" accent. Legitimate typographic characters (the `→`/`↗` arrows already used in nav and `CaseStudyNextNav`, curly quotes, em dashes, etc.) are not emoji and are unaffected by this rule.
- **Every PNG-sourced image with real transparent regions gets a white background when opened in the lightbox** (see `pngBackground` on `LightboxImage`/`CaseStudyFigure`, and the changelog entry above) — this is a standing rule for any future transparent-background image added to a case study, not a one-off fix. Determine "real transparency" by checking the actual file's alpha channel (a meaningful percentage of pixels below full opacity), not its extension — every image in this repo is served as `.webp`, so extension never distinguishes an originally-transparent PNG from an opaque photo. Ordinary opaque images (photos, most screenshots) should never get this prop.

**Known gaps** (not yet formalized): H1/H2 sizes in code not yet reconciled with the finalized Heading scale, no `Surface/Tint-*` background tokens, no breakpoint token — see [code-to-Figma mapping report](docs/figma-library-mapping.md).
